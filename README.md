# Dennise Birthday Card
A personal interactive birthday card created for Dennise, featuring a soft blue aesthetic, a handwritten-style birthday letter, a personal photo, and a music soundtrack.

## About
This project is a small digital birthday card made with the intention of turning a simple birthday greeting into a more personal and interactive experience.
It includes a landing screen, birthday reveal, photo display, background music, and a scrollable birthday letter written specifically for Dennise.

## Features
- Interactive birthday card opening
- Responsive design for desktop and mobile
- Personal photo display
- Custom birthday letter
- Background music with play and pause controls
- Soft blue visual theme
- Animated transitions and subtle effects

## Built With
- HTML5
- CSS3
- JavaScript
